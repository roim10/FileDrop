# FileDrop

Простой файловый сервер на Go с логированием и консольным клиентом. Учебный проект по темам работы с файлами/потоками и сетевого программирования.

## Что делает

- Сервер принимает файлы по HTTP и сохраняет их на диск
- Файлы можно скачать обратно или посмотреть список загруженного
- Все операции логируются в отдельный файл
- Консольный клиент общается с сервером через `http.Client` с таймаутом

## Стек

- Go
- `net/http`, `os`, `io`, `bufio`

## Структура проекта

```
filedrop/
├── go.mod
├── server/
│   └── main.go
├── client/
│   └── main.go
└── storage/        (создаётся сервером автоматически)
```

## Запуск

Сервер:

```bash
go run ./server
```

Сервер поднимется на `:8080`.

Клиент (в отдельном терминале):

```bash
go run ./client
```

## Эндпоинты сервера

| Метод | Путь | Описание |
|---|---|---|
| POST | `/upload?name=<filename>` | загрузить файл, тело запроса — содержимое файла |
| GET | `/download?name=<filename>` | скачать файл |
| GET | `/list` | список файлов в хранилище |
